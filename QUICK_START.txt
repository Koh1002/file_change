================================================================================
  固定長テキスト変換ツール - クイックスタートガイド
================================================================================

このツールには2つのバージョンがあります：

【標準版】
  - シンプルなUI（tkinter）
  - 軽量、高速起動

【モダン版】 ⭐おすすめ
  - モダンなUI（CustomTkinter）
  - Material Design風デザイン
  - ダークモード対応


================================================================================
開発・UI確認方法（EXE化不要）
================================================================================

【標準版を起動】
  1. run_app.bat をダブルクリック
  2. GUIウィンドウが開きます
  3. 動作確認後、ウィンドウを閉じる

【モダン版を起動】⭐おすすめ
  1. run_modern.bat をダブルクリック
  2. 初回のみCustomTkinterが自動インストールされます
  3. モダンなGUIウィンドウが開きます
  4. 動作確認後、ウィンドウを閉じる

※どちらも数秒で起動します（EXE化不要）


================================================================================
EXE化（配布用）
================================================================================

【標準版をEXE化】
  1. build_exe_en.bat をダブルクリック
  2. 3-5分待つ
  3. dist\FixedLengthConverter.exe が生成されます
  4. ファイルサイズ: 約15-20MB

【モダン版をEXE化】⭐おすすめ
  1. build_modern.bat をダブルクリック
  2. 3-5分待つ
  3. dist\FixedLengthConverter_Modern.exe が生成されます
  4. ファイルサイズ: 約25-30MB


================================================================================
どちらを使うべき？
================================================================================

【開発・UI確認中】
  → run_modern.bat（モダン版）
  - UIが見やすく、開発しやすい
  - 変更→起動→確認のサイクルが速い

【配布用EXE】
  → 標準版・モダン版どちらでもOK
  - 標準版: ファイルサイズが小さい
  - モダン版: UIが綺麗、ユーザー体験が良い

================================================================================
よくある質問
================================================================================

Q: run_modern.bat を実行するとエラーが出る

A: 初回のみCustomTkinterのインストールが必要です。
   インターネット接続を確認して再実行してください。
   自動でインストールされます。


Q: モダン版のEXEサイズが大きい

A: CustomTkinterは追加のライブラリを含むため、
   標準版より10MB程度大きくなります。
   それでも30MB程度なので問題ありません。


Q: 標準版とモダン版で機能は同じ？

A: はい、機能は全く同じです。
   見た目（UI/UX）のみが異なります。


Q: 変更後、すぐに動作確認したい

A: run_modern.bat をダブルクリックするだけです。
   数秒で起動するので、開発サイクルが速くなります。


================================================================================
推奨ワークフロー
================================================================================

【開発時】
  1. コード編集（app_modern.py など）
  2. run_modern.bat で動作確認
  3. 問題なければ git commit
  4. 必要に応じて build_modern.bat でEXE化

【配布時】
  1. build_modern.bat でEXE化
  2. dist\FixedLengthConverter_Modern.exe を配布
  3. README.txt も一緒に配布
