================================================================================
  アイコン設定ガイド
================================================================================

このガイドでは、アプリケーションにアイコンを追加する方法を説明します。


================================================================================
方法1：既存の画像を使用する（推奨）
================================================================================

1. 用意する画像
   - PNG形式またはICO形式
   - サイズ: 256x256ピクセル推奨
   - 透明背景推奨

2. 画像をプロジェクトフォルダに配置
   - icon.png または icon.ico という名前で保存
   - app_modern.py と同じフォルダに配置

3. 確認
   - run_modern.bat を実行
   - ウィンドウの左上にアイコンが表示されます
   - UIの左上（説明の横）にもロゴが表示されます


================================================================================
方法2：Pythonスクリプトでアイコンを作成する
================================================================================

シンプルな「ST」ロゴを自動生成する場合：

1. 必要なライブラリをインストール
   pip install Pillow

2. アイコン作成スクリプトを実行
   python create_icon.py

3. icon.png と icon.ico が生成されます

4. 確認
   run_modern.bat を実行してアイコンを確認


================================================================================
EXE化時のアイコン設定
================================================================================

build_modern.bat を実行すると、自動的に以下を行います：

1. icon.ico が存在する場合
   - EXEファイルのアイコンとして使用
   - Windows エクスプローラーで表示されるアイコンになります

2. icon.ico が存在しない場合
   - デフォルトのPythonアイコンが使用されます


================================================================================
画像の推奨仕様
================================================================================

【ファイル形式】
  - PNG: 透明背景が使える、高品質
  - ICO: Windows標準、複数サイズを含められる

【サイズ】
  - 最小: 128x128ピクセル
  - 推奨: 256x256ピクセル
  - 最大: 512x512ピクセル

【デザイン】
  - シンプルでわかりやすいデザイン
  - 会社ロゴやアプリ名の頭文字など
  - 背景は透明または単色


================================================================================
トラブルシューティング
================================================================================

Q: アイコンが表示されない

A: 以下を確認してください：
   1. icon.png または icon.ico がプロジェクトフォルダにあるか
   2. ファイル名が正しいか（大文字小文字も含む）
   3. Pillowがインストールされているか: pip install Pillow


Q: EXEのアイコンが変わらない

A: 以下を確認してください：
   1. icon.ico が存在するか（icon.pngではなくico形式が必要）
   2. ビルド前に icon.ico を配置したか
   3. 古いEXEファイルを削除してから再ビルドしたか


Q: 画像をICO形式に変換したい

A: 以下のツールを使用できます：
   1. オンライン変換ツール（「PNG to ICO」で検索）
   2. Photoshop / GIMP などの画像編集ソフト
   3. create_icon.py を修正して使用


Q: 独自の画像を使いたい

A: 以下の手順で設定できます：
   1. 画像を icon.png という名前で保存
   2. プロジェクトフォルダに配置
   3. ICO形式が必要な場合は変換ツールを使用
   4. build_modern.bat を実行


================================================================================
参考：create_icon.py の使い方
================================================================================

デフォルトでは「ST」（Simple Text Converter）のロゴを作成します。

カスタマイズしたい場合は、create_icon.py を編集してください：

1. 背景色を変更
   color='#2196F3'  ← ここを変更

2. テキストを変更
   text = "ST"  ← ここを変更

3. フォントサイズを変更
   font = ImageFont.truetype("arial.ttf", 100)  ← 100を変更
