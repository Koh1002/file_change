1. このツールについて
================================================================================

このツールは、カード番号と入金額を入力するだけで、指定フォーマットの
固定長テキストファイル（Shift_JIS、CRLF）を自動生成します。

【機能】
  - 一括アクティベート登録（アップロード）用ファイル生成
  - 一括入金登録（アップロード）用ファイル生成

【特徴】
  - Pythonのインストール不要（EXE単体で動作）
  - Excel等からコピー＆ペーストで簡単入力
  - 入力内容を自動バリデーション
  - 固定長（254文字 + CRLF）を自動生成

2. EXEファイルの準備（開発者向け）
================================================================================

【Windows環境でのビルド - 推奨方法】

  ◆方法1：簡易ビルドスクリプト（初心者向け）

    1. Pythonがインストールされていることを確認
       - Python 3.8以降を推奨
       - https://www.python.org/downloads/ からダウンロード
       - インストール時に「Add Python to PATH」にチェックを入れること

    2. build_exe_simple.bat を右クリック → 「管理者として実行」

    3. 画面の指示に従ってEnterキーを押していく

    4. ビルドが完了すると、dist フォルダに
       「固定長テキスト変換ツール.exe」が生成されます

    ※このスクリプトは詳細なエラーメッセージを表示するため、
      問題が発生した場合でも原因を特定しやすくなっています。

  ◆方法2：通常ビルドスクリプト

    1. build_exe.bat をダブルクリック

    2. ウィンドウが閉じずに処理が進行します

    3. エラーが発生した場合は、詳細なメッセージが表示されます

    4. 完了後、Enterキーで終了

  ◆トラブルシューティング

    【問題】ウィンドウが一瞬で閉じてしまう
    【解決】build_exe_simple.bat を使用してください

    【問題】「Pythonが見つかりません」と表示される
    【解決】Pythonをインストールし、PATHに追加してください
           コンピュータを再起動すると解決する場合もあります

    【問題】「仮想環境の作成に失敗しました」と表示される
    【解決】管理者権限でスクリプトを実行してください
           右クリック → 「管理者として実行」

    【問題】ビルドに失敗する
    【解決】以下のフォルダを削除してから再実行：
           - venv フォルダ
           - build フォルダ
           - dist フォルダ

【Linux/Mac環境でのビルド】

  1. ターミナルで以下を実行：
     $ chmod +x build_exe.sh
     $ ./build_exe.sh

  2. dist フォルダに実行ファイルが生成されます


【手動ビルド（上級者向け）】

  1. 仮想環境を作成してアクティベート：
     > python -m venv venv
     > venv\Scripts\activate     （Windowsの場合）
     $ source venv/bin/activate  （Linux/Macの場合）

  2. PyInstallerをインストール：
     > pip install pyinstaller

  3. EXEをビルド：
     > pyinstaller --onefile --noconsole --name "固定長テキスト変換ツール" app.py

  4. dist フォルダにEXEファイルが生成されます

3. 使い方（利用者向け）
================================================================================

【基本的な流れ】

  1. 「固定長テキスト変換ツール.exe」をダブルクリックして起動

  2. タブを選択
     - 「一括アクティベート」タブ
     - 「一括入金」タブ

  3. データを入力
     - Excelで「カード番号」「入金額」を2列で用意
     - 該当範囲をコピーして、テキストエリアに貼り付け
     - または、直接「カード番号,入金額」形式で入力

  4. 「ファイルを生成」ボタンをクリック

  5. 保存先とファイル名を指定して保存

  6. 「作成完了」ダイアログが表示されたら完了

  ※カード発行会社コードは「7130754」で固定されています


【サンプルボタンの使い方】

  - 「サンプル貼り付け」ボタンをクリックすると、
    サンプルデータが自動入力されます
  - 初めて使う場合は、まずサンプルで試してみてください


【クリアボタン】

  - 入力内容をすべて削除したい場合は「クリア」ボタンをクリック


================================================================================
4. 入力フォーマット
================================================================================

【基本フォーマット】
  カード番号,入金額

【例】
  7130123456789012,10000
  7130123456789013,20000
  7130123456789014,5000

【入力ルール】

  ◆カード番号
    - 16桁の半角数字
    - 全角数字は使用不可

  ◆入金額
    - 最大7桁の半角数字（0〜9999999）
    - 全角数字は使用不可

  ◆区切り文字
    - カンマ（,）またはタブで区切る
    - Excelからコピペする場合は自動的にタブ区切りになります

  ◆最大件数
    - 1回の処理で最大100,000件まで


【Excelからの貼り付け手順】

  1. Excelで以下のような表を用意：
     ┌──────────────┬────────┐
     │ カード番号       │ 入金額 │
     ├──────────────┼────────┤
     │ 7130123456789012 │ 10000  │
     │ 7130123456789013 │ 20000  │
     │ 7130123456789014 │ 5000   │
     └──────────────┴────────┘

  2. データ部分のみを選択してコピー（見出し行は除く）

  3. ツールのテキストエリアに貼り付け


================================================================================
5. 出力フォーマット
================================================================================

【ファイル仕様】
  - 文字コード：Shift_JIS
  - 改行コード：CRLF（Windows形式）
  - レコード長：254文字 + CRLF（合計256バイト/行）

【レコード構成】
  1行目：ヘッダーレコード（データ区分=1）
  2行目以降：データレコード（データ区分=2）× N行
  最後から2行目：トレーラーレコード（データ区分=8）
  最終行：エンドレコード（データ区分=9）

【一括アクティベートと一括入金の違い】
  - ヘッダーレコードの取引区分が異なります
    - 一括アクティベート：0201
    - 一括入金：0202

【固定値】
  - データレコードには以下の固定値が自動設定されます：
    - 項番7：998
    - 項番8：2
    - 項番9：A102

【デフォルトファイル名】
  - トモズ様_一括アクティベート_YYYYMMDDhhmmss.txt
  - トモズ様_一括入金_YYYYMMDDhhmmss.txt
  ※タイムスタンプ付きで自動生成されますが、保存時に変更可能です

6. トラブルシューティング
================================================================================

【Q1】EXEファイルが起動しない

  A：以下を確認してください：
    - Windows 10以降であることを確認
    - セキュリティソフトがブロックしていないか確認
    - EXEファイルを右クリック → プロパティ → ブロック解除

【Q2】「カード番号は16桁の半角数字で入力してください」と表示される

  A：以下を確認してください：
    - 全角数字になっていないか
    - カード番号が16桁であるか
    - ハイフン等の記号が含まれていないか

【Q3】「入金額は7桁以内の半角数字で入力してください」と表示される

  A：以下を確認してください：
    - 全角数字になっていないか
    - 入金額が7桁を超えていないか（最大9999999）
    - カンマ等の記号が含まれていないか

【Q4】Excelから貼り付けるとエラーになる

  A：以下を確認してください：
    - 見出し行を除いてデータ部分のみをコピーしているか
    - 空行が含まれていないか（空行は自動スキップされます）
    - セルにスペースや改行が含まれていないか

【Q5】生成されたファイルが開けない

  A：以下を確認してください：
    - Shift_JIS対応のテキストエディタで開く
      （メモ帳、秀丸、サクラエディタ等）
    - UTF-8専用エディタでは文字化けする可能性があります

【Q6】カード発行会社コードは変更できますか？

  A：カード発行会社コードは「7130754」で固定されています。
     変更する必要がある場合は、開発者にお問い合わせください。
