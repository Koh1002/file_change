================================================================================
  固定長テキスト変換ツール - ビルド手順書（トラブルシューティング版）
================================================================================

バッチファイルが正常に動作しない場合は、以下の手順で手動ビルドしてください。


【手順1】バッチファイルの動作確認
================================================================================

まず、バッチファイルが正常に動作するか確認します。

1. test_bat.bat をダブルクリック

2. ウィンドウが開いて、以下のようなメッセージが表示されるか確認：
   ========================================
   バッチファイル動作テスト
   ========================================

   このメッセージが表示されれば、バッチファイルは動作しています。

3. Pythonのバージョンが表示されれば成功

【結果】
  [OK] 表示される → 手順2へ進む
  [NG] ウィンドウが一瞬で閉じる → 手順3（コマンドプロンプトから実行）へ


【手順2】デバッグ版でビルド（ログ出力あり）
================================================================================

デバッグ版のバッチファイルを使用して、詳細なログを確認します。

1. build_exe_debug.bat をダブルクリック

2. ウィンドウが開いて処理が進行するのを確認

3. エラーが発生した場合：
   - 同じフォルダに build_log.txt が作成されます
   - build_log.txt をメモ帳で開いて、エラー内容を確認してください

4. ビルドが成功した場合：
   - dist フォルダが作成されます
   - dist\固定長テキスト変換ツール.exe が生成されます


【手順3】コマンドプロンプトから手動実行
================================================================================

バッチファイルのダブルクリックが動作しない場合は、コマンドプロンプトから実行します。

1. エクスプローラーで、このフォルダ（build_exe.bat があるフォルダ）を開く

2. アドレスバー（フォルダパスが表示されている部分）をクリック

3. 「cmd」と入力してEnterキーを押す
   → コマンドプロンプトがこのフォルダで開きます

4. 以下のコマンドを1行ずつ実行：

   【Python確認】
   python --version

   または

   py --version

   → Pythonのバージョンが表示されればOK

   【仮想環境作成】
   python -m venv venv

   または

   py -m venv venv

   → エラーが出なければOK

   【仮想環境アクティベート】
   venv\Scripts\activate

   → コマンドプロンプトの先頭に (venv) が表示されればOK

   【PyInstallerインストール】
   pip install pyinstaller

   → インストールが完了するまで待つ（数分かかります）

   【EXEビルド】
   pyinstaller --onefile --noconsole --name 固定長テキスト変換ツール app.py

   → ビルドが完了するまで待つ（3-5分かかります）

5. ビルドが完了したら：
   - dist フォルダを確認
   - 「固定長テキスト変換ツール.exe」が作成されていれば成功


【手順4】エラーが発生した場合
================================================================================

◆ 「Pythonが見つかりません」というエラー

  【原因】Pythonがインストールされていない、またはPATHに追加されていない

  【解決策】
  1. Python 3.8以降をインストール
     https://www.python.org/downloads/

  2. インストール時に必ず「Add Python to PATH」にチェックを入れる

  3. インストール後、コンピュータを再起動


◆ 「仮想環境の作成に失敗しました」というエラー

  【原因】ディスク容量不足、権限の問題

  【解決策】
  1. 管理者権限でコマンドプロンプトを開く
     - スタートメニュー → 「cmd」と検索
     - コマンドプロンプトを右クリック → 「管理者として実行」

  2. 上記の手順3を再実行


◆ 「PyInstallerのインストールに失敗しました」というエラー

  【原因】インターネット接続の問題

  【解決策】
  1. インターネット接続を確認

  2. pipを最新版にアップデート：
     python -m pip install --upgrade pip

  3. 再度PyInstallerをインストール：
     pip install pyinstaller


◆ ビルドは成功するが、EXEが作成されない

  【原因】セキュリティソフトがブロックしている可能性

  【解決策】
  1. build_log.txt を確認

  2. セキュリティソフトの設定を確認
     - PyInstallerを許可リストに追加
     - 一時的にセキュリティソフトを無効化してビルド

  3. build、dist、venv フォルダを削除して再実行


◆ その他のエラー

  【確認事項】
  1. build_log.txt の内容を確認

  2. 以下のフォルダを削除して再実行：
     - venv フォルダ
     - build フォルダ
     - dist フォルダ
     - __pycache__ フォルダ
     - *.spec ファイル

  3. コンピュータを再起動して再実行


【手順5】成功後の確認
================================================================================

1. dist フォルダを開く

2. 「固定長テキスト変換ツール.exe」をダブルクリック

3. GUIウィンドウが開けば成功

4. サンプルデータで動作確認：
   - 「サンプル貼り付け」ボタンをクリック
   - 「ファイルを生成」ボタンをクリック
   - ファイルが生成できれば完了


【よくある質問】
================================================================================

Q: バッチファイルをダブルクリックしても何も起きない

A: 以下を確認してください：
   - ファイルの拡張子が .bat になっているか
   - セキュリティソフトがブロックしていないか
   - ファイルを右クリック → プロパティ → ブロック解除


Q: コマンドプロンプトの使い方がわからない

A: 上記の手順3を参照してください。
   フォルダのアドレスバーに「cmd」と入力するのが最も簡単です。


Q: 管理者権限での実行方法がわからない

A:
   - バッチファイルを右クリック → 「管理者として実行」
   - または、コマンドプロンプトを管理者として実行してから手順3を実行


Q: ビルドに時間がかかりすぎる

A: PyInstallerのビルドは通常3-5分かかります。
   10分以上かかる場合は、Ctrl+C で中断して再実行してください。


【サポート】
================================================================================

上記の手順を試してもうまくいかない場合は、以下の情報を添えて開発者に連絡してください：

1. build_log.txt の内容（存在する場合）
2. エラーメッセージのスクリーンショット
3. Windowsのバージョン
4. Pythonのバージョン（python --version の結果）
